# 04 — Originality, Licensing and IP Provenance

## Why this is a hard gate

Contest terms disqualify pre-existing builds, reskins and substantially copied games. The broader 21-batch Mixipelago documentation is a *concept/design roadmap*, not an eligible pre-existing submitted game. The contest implementation must be a **new Base44-created game during the contest window**, with original expression, distinctive gameplay presentation and auditable asset sourcing. Do not assume older screenshots or gameplay references may be reused in the finished submission.

## Original game signature

- A seaside **service simulation** wrapped around a physical merging puzzle: customer requests change how chains are planned.
- Tactile drink collisions, splashes, layered-color evolution, consistent stylized 2.5D shadows and restrained motion.
- Coconut Cove map, original vendors and scenery, three chapters and a distinctive festival shift.
- Visible order priority, meaningful bounded danger and coherent narrative presentation.
- Unique mix of service rules, aesthetic, character names, level design and controls; no direct mirroring of the reference game's structure or distinctive art composition.

## Asset policy

Every published asset receives a rights row before release:

| Field | Meaning |
|---|---|
| assetId, filename, sha256 | Stable origin and integrity |
| mediaType, intendedUsage | Art, SFX, font, animation, UI |
| creator/tool/model | Human creation or AI tool/version; prompts/history if applicable |
| creationDateUTC | When made, ideally within contest window |
| licence/permission | Owned work, written contributor assignment, or verified open licence |
| attributionRequired | Exact notice and placement, if any |
| thirdPartyReferenceRisk | Source game, brand, logo, likeness resemblance review |
| reviewedBy/status | Approved/rejected/replaced |

Store copyright permission documents in secure workspace; GitHub can hold non-sensitive summaries and original source exports. AI-generation itself does not establish ownership or non-infringement.

## Prohibited practices

- Cropping the source game screenshots as sprites or UI.
- Tracing another game's exact HUD, backdrop, mascots, music, level layout or branded names.
- Unlicensed sounds from videos, streaming sites, commercial music, or paid font packs.
- Using recognizable movie/cartoon characters or real-person likenesses without appropriate rights.
- Passing an unchanged tutorial or sample game as the final entry.
- Treating a stock/background package as automatically sublicensable without reviewing its terms.

## Visual review checklist

- [ ] Sprite silhouettes are distinctive, not palette swaps of references.
- [ ] Island map is original; level paths and HUD don't replicate the source composition.
- [ ] SFX/music are original or licensed for public hosted game and contest promotional licence.
- [ ] All fonts/icons have documented permissible embedding and attribution.
- [ ] All assets have rights ID, SHA-256 and reviewer sign-off.
- [ ] No third-party logos or brand marks embedded in game screenshots.
- [ ] Product name and wordmark checked for confusing similarity before launch.
- [ ] Contributor rights/assignments and any AI terms verified.

## Evidence versus disclosure

Never fabricate provenance or backdate source files. Record actual historical development honestly; original concept preparation and new game implementation are distinct facts. If the organizer interprets earlier concept work as a pre-existing project, request a ruling rather than asserting eligibility.
