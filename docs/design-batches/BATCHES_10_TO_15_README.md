On GitHub, use `docs/design-batches/Batch_10_*` through `Batch_15_*`. Preserve the numbered chapters, examples, schemas, tests, contracts and tools. This is documentation, not a game implementation.

## User acceptance
Engineers own automated tests and PRs; manual UI/gameplay tests must be directed to the project owner.
