# Batch 5 Content Manifest

- `docs/`: detailed Markdown engineering/design specifications, chapters 00–39.
- `examples/worlds/`: one small staged candidate and one larger **draft** creative graph.
- `examples/missions/`: exact copied Batch 4 v1 Coconut Cove missions.
- `examples/schemas/`: campaign graph schema with constrained rule DSL.
- `examples/tests/`: pure rule vectors and negative graph fixtures.
- `examples/assets/`: example keys only, not real asset files.
- `examples/contracts/`: semantic event examples, no backend implementation.
- `tools/validate_batch5.py`: static lint and unit-like examples.

*No real scenes, island assets, deployed frontend, physical proof, genuine account progress or currency service were produced in this documentation-only batch.*
