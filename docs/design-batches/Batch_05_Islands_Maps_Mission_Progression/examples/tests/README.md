# Test fixtures

- `unlock-rule-vectors.json` contains pure expression evaluation cases.
- Seven `*.json` graph variants are **intentionally invalid** and should fail validation.
- These tests are structural/progression tests only. They do not simulate real physics, prove missions solvable, verify UI behavior or establish spendable economy receipts.
- `coconut-cove-starter.staged.json` is a candidate that has **not** passed owner manual gameplay approval or headless golden replays.
- `coconut-cove-26-node-concept.draft.json` contains many future *nonplayable* placeholders, which the public loader must filter.
