# Content Manifest

Candidate content only. The draft catalog includes 14 achievements, 24 unique collectible/cosmetic item IDs, 3 albums, 19 proposed reward policies and 2 chest definitions; the weighted chest is a deliberately **disabled design example**, not live gameplay.

`examples/` contains schemas, pure rule vectors, API examples, TypeScript reference and SQL sketch. `tools/validate_batch8.py` checks static validity and fixtures; it does not run physics, authenticate API requests or deploy migrations.

All previously authored gameplay contracts remain unchanged.
